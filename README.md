# SmartResQ – IoT-Based Automated Emergency Alert System

## Project Overview
SmartResQ is an IoT-based vehicle emergency alert system designed to detect critical situations such as accident impacts and fire incidents. It also provides a manual option to trigger medical emergency alerts.

The system uses an ESP32-based setup to identify emergency events and integrates Twilio for sending automated SMS notifications and initiating voice calls to predefined emergency contacts.

## Key Features
- **Accident Impact Detection:** Detects vehicle impact events.
- **Fire Detection:** Identifies fire-related emergencies.
- **Manual Emergency Alert:** Enables users to trigger medical emergency notifications manually.
- **Automated Notifications:** Sends SMS alerts and voice calls to predefined contacts using Twilio.

## Technology Stack
- **Microcontroller:** ESP32
- **Sensors:** MPU6050, IR Flame Sensor
- **Communication:** Twilio API
- **Alert Mechanism:** SMS and Voice Calls
- **Hardware Components:** Buzzer and supporting electronic components
